# qwen-on-12gb — большая модель на слабой видеокарте

Пошаговая установка **Qwen3.8-Flash-Next** (176 млрд параметров, 6 активных на токен)
на RTX 3060 с 12 ГБ видеопамяти. Результат: **21 токен/с** на генерации, 189 на обработке
запроса.

Работает это потому, что модель не обязана целиком лежать в видеопамяти: разреженная MoE
держит экспертов в оперативной, mmap оставляет 36 ГБ таблицы n-грамм на диске, а карте
достаются только слои внимания — 9,2 ГБ из 12,3.

Разбор, зачем и как это устроено — [пост в канале](https://t.me/bender_CIO/11).

## Рецепт

Проверено на Ubuntu 24.04, RTX 3060 12 ГБ, 62 ГБ оперативной, драйвер 580. Права администратора не нужны ни на одном шаге. Диска потребуется 90 ГБ.

**1. Модель.** Сборка AtomicChat, 89 ГБ, 33 шарда. Плюс проектор — без него не будет картинок.

`pip install huggingface_hub`
`hf download AtomicChat/Qwen3.8-Flash-Next-GGUF --include "*AD-4.27bpw-Q4_K_M-M64*" "mmproj-*F16.gguf" --local-dir ~/models/qwen38`

У меня скачалось за 13 минут на 72 МБ/с. Есть сборка полегче, 3,84 бита: она на 8 ГБ меньше и в полтора раза медленнее, брать её смысла нет.

**2. CUDA без root.** Ставится пакетами Python в отдельное окружение:

`python3 -m venv ~/build/cudaenv`
`~/build/cudaenv/bin/pip install nvidia-cuda-nvcc nvidia-cuda-runtime nvidia-cublas nvidia-cuda-cccl`

Имена пакетов без суффикса `-cu13`: версии с ним устарели и валятся при сборке. Дальше приводим раскладку к виду обычного тулкита:

`export CU=~/build/cudaenv/lib/python3.12/site-packages/nvidia/cu13`
`cd $CU && mv lib64 lib && cd lib`
`for f in libcublas libcublasLt libcudart libnvrtc; do ln -sf $f.so.13 $f.so; done`

Без этих симлинков cmake не найдёт cuBLAS и сборка встанет.

**3. cmake.** В репозиториях старый, нужен свежий. Скачайте бинарный архив с github.com/Kitware/CMake/releases и распакуйте, у меня `~/build/cmake-3.31.6-linux-x86_64`.

**4. llama.cpp из master.** Поддержку архитектуры влили 27 августа, в релиз она не попала.

`git clone https://github.com/ggml-org/llama.cpp ~/build/llama.cpp && cd ~/build/llama.cpp`
`~/build/cmake-3.31.6-linux-x86_64/bin/cmake -B build-cuda -DGGML_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=86 -DCUDAToolkit_ROOT=$CU`
`~/build/cmake-3.31.6-linux-x86_64/bin/cmake --build build-cuda --config Release -j`

`86` — это 30-я серия карт. Для 40-й ставьте `89`, для 50-й `120`. Сборка заняла девять минут.

**5. Запуск.**

`LD_LIBRARY_PATH=$CU/lib ~/build/llama.cpp/build-cuda/bin/llama-server -m ~/models/qwen38/Qwen3.8-Flash-Next-AD-4.27bpw-Q4_K_M-M64-00001-of-00033.gguf --mmproj ~/models/qwen38/mmproj-Qwen3.8-Flash-Next-F16.gguf -fit off -ngl 99 --n-cpu-moe 44 -t 26 -c 8192 --parallel 1 --jinja --reasoning-effort medium --host 127.0.0.1 --port 8080`

Про флаги, по которым спотыкаются.

`--n-cpu-moe 44` — сколько слоёв экспертов остаётся на процессоре. Это главная ручка: меньше число — больше уезжает на карту и быстрее счёт, но если видеопамяти не хватит, сервер не поднимется. У меня при 44 занято 9,2 ГБ из 12,3. Начните с 48 и уменьшайте.

`-fit off` — отключает автоподбор параметров. С ним модель не стартует, это указание самого издателя сборки.

`--jinja` — обязателен. Без него не применяется шаблон чата, и следующий флаг молча не сработает.

`--reasoning-effort medium` — в шаблоне зашит `xhigh`, на нём модель сжигает две тысячи токенов на размышления и может не начать ответ. На `medium` у меня 9 задач из 9 против 8, и вдвое меньше токенов.

`-t 26` — потоки по числу ядер процессора. `-c 8192` — контекст: для картинок меньше нельзя, один кадр весит 4171 токен.

И не отключайте mmap. Именно он оставляет 36 гигабайт таблицы n-грамм на диске вместо памяти.

Проверить, что живо: `curl 127.0.0.1:8080/health`. Дальше это обычный OpenAI-совместимый сервер на `/v1/chat/completions`.

## Замеры на этом стенде

| | |
|---|---|
| Генерация | 21,1 токена/с |
| Обработка запроса | 189 токенов/с |
| Без видеокарты | 5 токенов/с |
| Занято на карте | 9,2 ГБ из 12,3 |
| В оперативной памяти | 45,8 ГБ |
| На диске (таблица n-грамм) | 36 ГБ |

Для сравнения: MacBook Pro M5 Max с 64 ГБ выдаёт 36 токенов/с — быстрее в 1,7 раза.

## Оговорки

Числа сняты на конкретной машине: i7-14700K, 62 ГБ DDR5, RTX 3060 12 ГБ, драйвер 580,
живой хост с работающими контейнерами. Стенд не стерильный.

Команда `hf download` из шага 1 приведена по документации huggingface_hub и на этой машине
не выполнялась: модель скачивалась другим способом. Остальные шаги выполнены полностью.
