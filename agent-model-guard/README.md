# agent-model-guard — субагент не уедет на дорогой модели молча

Если при запуске субагента не указать модель, он **наследует модель родителя**. Родитель
обычно сильная модель — она же планирует работу. В итоге механика (вычитка корпусов, парсинг,
заполнение таблиц) идёт по премиум-тарифу, и в отчётах это никак не видно.

Замер на живой работе: из **71 запуска субагента явную модель имели два**. Остальные 69 ушли
по модели родителя — около **6,5 млн токенов** старшей модели там, где хватило бы дешёвой.

Правило текстом («всегда указывай модель») не помогло: через месяц замер показал те же цифры.
Помогло событие — хук, который просто не пускает запуск без явного параметра.

## Что делает

Перехватывает вызов инструмента `Agent`. Если тип субагента — catch-all (`general-purpose`
или `claude`) и параметр `model` не задан, запуск **отклоняется** с объяснением. Модель
за вас хук не выбирает: он запрещает молчаливое наследование.

Типы со своим определением модели и `fork` (он наследует родителя по определению)
пропускаются без вопросов.

## Установка

```bash
mkdir -p ~/.claude/hooks
cp agent-model-guard.sh ~/.claude/hooks/
chmod +x ~/.claude/hooks/agent-model-guard.sh
```

В `~/.claude/settings.json`:

```json
{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Agent",
        "hooks": [ { "type": "command", "command": "bash $HOME/.claude/hooks/agent-model-guard.sh" } ] }
    ]
  }
}
```

## Проверка

```bash
# без модели — блокирует (код 2)
echo '{"tool_input":{"subagent_type":"general-purpose"}}' | bash ~/.claude/hooks/agent-model-guard.sh; echo $?

# с моделью — пропускает (код 0)
echo '{"tool_input":{"subagent_type":"general-purpose","model":"sonnet"}}' | bash ~/.claude/hooks/agent-model-guard.sh; echo $?
```

## Как выбирать модель

| Задача | Модель |
|---|---|
| Массовое чтение, выборка, парсинг, заполнение схемы | дешёвая (`sonnet`) |
| Синтез, спорное решение, разбор противоречий, red-team | старшая, указанная явно |

Отдельный приём под ту же боль: когда данных много, а нужна глубина — механический сбор
отдаёте дешёвой модели, и она возвращает **структурированный пакет** (вопрос, ограничения,
факты со ссылками на источник, что осталось неизвестным, варианты решения), а не дамп.
Старшая модель получает пакет и выносит суждение. Экономит лимит кратно и снижает шум
в контексте.

## Оговорки

Скрипт читает JSON вызова со стандартного входа и печатает отказ в stderr. Ничего не отправляет
наружу, не пишет на диск, не обновляется сам.

⚠ Всё, что попадает в `hooks`, ваш агент выполняет автоматически. Прочитайте код перед
установкой — это относится к любому чужому хуку, не только к этому.

Имена типов субагентов (`general-purpose`, `claude`, `fork`) зависят от вашей сборки —
проверьте свои и поправьте `case` в скрипте, если они отличаются.
