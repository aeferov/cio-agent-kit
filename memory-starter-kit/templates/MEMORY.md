# Память проекта <название>

Индекс заметок: одна строка на файл. Сам файл — один факт, одно решение или один
открытый вопрос. Индекс подгружается в каждую сессию целиком, остальное агент
дочитывает по надобности — так экономится контекст.

## Правила против разрастания

- Новая заметка — только если нет близкой. Есть — обновляй её, а не плоди вторую.
- Устаревшее и опровергнутое удаляй, а не копи: память должна быть меньше проекта.
- Заметка — точечный снимок прошлого. Прежде чем утверждать по ней, сверься с кодом:
  путь, флаг или число могли измениться.
