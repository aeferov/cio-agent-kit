# now-stamp — штамп времени в каждой реплике

У модели нет часов. Дата приходит в системном контексте, времени там нет вообще:
узнать его можно, только выполнив команду. Между вашими репликами проходит
произвольный интервал — попрощались в 00:17, вернулись в 10:42, а для агента это
тот же момент разговора, и он продолжает рассуждать по протухшему времени.

Хук вешает на каждую вашу реплику строку вида:

```
— сейчас: 17:22 MSK, Saturday 29.08.2026
```

## Установка

```bash
mkdir -p ~/.claude/hooks
cp now-stamp.sh ~/.claude/hooks/
chmod +x ~/.claude/hooks/now-stamp.sh
```

В `~/.claude/settings.json`:

```json
{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [ { "type": "command", "command": "bash $HOME/.claude/hooks/now-stamp.sh" } ] }
    ]
  }
}
```

## Настройка

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `NOW_STAMP_TZ_HOME` | основная зона | `Europe/Moscow` |
| `NOW_STAMP_TZ_ALT` | вторая зона (в поездке) | не задана |

Вторая зона печатается, **только если смещение реально отличается**. Иначе в контекст
лезет бессмысленный дубль «10:42 и 10:42» — на этом и споткнулась первая версия.

## Что скрипт делает и чего не делает

Читает системные часы, печатает одну строку. Не ходит в сеть, ничего не отправляет,
не обновляется сам, не пишет на диск.

⚠ Всё, что попадает в `hooks`, ваш агент выполняет на каждой реплике. Прочитайте код
перед установкой — это относится к любому чужому хуку, не только к этому.
